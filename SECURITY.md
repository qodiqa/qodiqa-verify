# Security policy

A verifier that accepts forged evidence is a serious bug, so reports are welcome.

Report privately: use GitHub private vulnerability reporting (Security tab, "Report a vulnerability"), or email security@qodiqa.com. Please do not open a public issue.

We acknowledge within 5 working days, give a first assessment within 15, and ask for 90 days of coordinated disclosure. These are targets for a small team, not guarantees.

In scope: false VALID verdicts, crashes or hangs on hostile input, and differences between the JavaScript and Python implementations on the same vector. Out of scope: a compromised host or a wrong trust anchor supplied by the user.

There is no stable release yet; fixes go to the default branch.
